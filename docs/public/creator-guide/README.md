# Gutch Creator Guide

This guide is for creators preparing a product for Gutch.

Here, `product` can mean a game, an app, a software tool, an asset pack, an image pack, or any other downloadable versioned content. The goal is not to explain every internal detail of Gutch. The goal is to explain how to package and release your product so Gutch can store it efficiently, deliver it cleanly, and repair it safely later.

## Short Version

If you want one rule to remember, use this:

- separate content by ownership and purpose
- keep packaging stable
- avoid rewriting unrelated bytes

That is the direction Gutch rewards.

For canonical internal terminology and design rules, see `gutch/docs/README.md`.
